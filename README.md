# 📊 Adventure Works Sales Dashboard (Excel)

An interactive **Excel Sales Dashboard** created using pivot tables, dynamic charts, and slicers. It provides clear insights into sales trends, product performance, regional distribution, and customer behavior, helping users make quick, data-driven decisions.

---

## 🔍 **Features**

* Dynamic charts and KPIs for total sales, profit, and order count
* Slicers for filtering by year, region, customer segment, and category
* Trend analysis for monthly and yearly sales
* Category-wise and region-wise performance insights
* Clean, professional, and user-friendly layout

---

## 🛠️ **Tools Used**

* Microsoft Excel
* Pivot Tables & Pivot Charts
* Power Query for data cleaning
* Conditional Formatting
* Excel Formulas (LOOKUPs, Aggregations, Date functions)

1. Download the Excel file
2. Enable **Editing** and **Content** (if prompted)

4. Explore interactive charts and KPIs for deeper analysis
